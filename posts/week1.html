Giant component

The one trap the course warns about: a careless load builds the graph from the edge list alone and silently drops the 17 characters with no link in either direction. We add the node roster first, then the edges.

import pandas as pd
import networkx as nx

nodes = pd.read_csv("Data/week1_nodes.tsv", sep="\t", comment="#")
edges = pd.read_csv("Data/week1_edges.tsv", sep="\t", comment="#",
                    names=["source", "target"])

G = nx.DiGraph()
G.add_nodes_from(nodes.node_id)                     # all 303 — isolates included
G.add_edges_from(edges.itertuples(index=False, name=None))

print(G.number_of_nodes(), G.number_of_edges())     # 303 1784
print(sum(1 for n in G if G.degree(n) == 0))        # 17 isolates
